Data Format Requirements

The uploaded CSV file should meet the following requirements:

  • Include a Date column with values in YYYY-MM-DD format
  • Include a Price column with numerical values
  • Data should be sorted chronologically
  • No missing values or gaps in the time series

Example format:

Date,Price
2020-01-01,63.05
2020-01-02,61.18
2020-01-03,63.05
...
